# Workspace Booking Service

RESTful API сервис для бронирования рабочих мест, офисов и переговорных комнат.

## Стек использованный при разработке
Проект разработан на языке программирования **Java 21**, фреймворк и его библеотеки **Spring Boot 4.1.1, Spring Web, Spring Data JPA, Spring Security**, база данных **PostgreSQL**, документация API: **Swagger UI / OpenAPI 3.0**, Сборщик проекта: **Maven**, Вспомогательные библиотеки: **Lombok, Jakarta Validation**

### Статус и реализованный функционал

Проект в процессе активной разработки.

[x] Реализованы CRUD-эндпоинты для управления.
